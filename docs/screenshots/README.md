## 投稿规范

- 格式 PNG（必要时 WebP），宽度 1600–2000 px，不放大段空白边。
- 截图里不要出现真实文档内容、本机路径、最近文件列表或个人信息；用示例文档。
- 文件名用小写短横线：`editor-light.png`、`math-mermaid.png`、`code-block.png`。
- 放进本目录后，在根目录 `README.md` 的“截图 / Screenshots”一节用 Markdown 图片语法引用。
- 若图片较大，先压缩到单张 500 KB 以内，避免拖慢 README 加载。
