# Screenshots

All images in this directory are **real application screenshots**, captured from a Lumin window
running against a demo document (`demo.md`) in an isolated profile. The UI was set to English and
the light theme. Nothing here is a mockup or a composite. The demo document, window, and profile
contain no personal paths, user names, or private documents.

Notes for contributors:

- Capture from the real app, not from a design tool. Keep the demo document generic.
- Do not include desktop chrome, taskbars, recent-file lists, absolute paths, or account names.
- Keep the width at 1400 px or less and each file under 500 KB; optimize PNG before committing.
- Reference images from the READMEs with relative paths (`docs/screenshots/<name>.png`).
