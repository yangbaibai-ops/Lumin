Lumin
===

> 所见即所得的 Markdown 编辑器。

![构建状态](https://img.shields.io/badge/build-passing-green)

## 特性

- **实时渲染**：输入 `#` 即变标题
- 表格、任务列表、公式 $E = mc^2$
- 代码高亮（含 `mermaid` 图表）

### 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+S` | 保存 |
| `Ctrl+N` | 新建 |

## 代码示例

```js
export function hello(name) {
  return `你好，${name}`
}
```
