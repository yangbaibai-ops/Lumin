# Lumin — Write in Light

一款 **Windows 优先**的所见即所得 Markdown 编辑器。

**Electron 39 · Vue 3.5 · Tiptap v3 · CodeMirror 6 · Mermaid 11 · KaTeX 0.18**

打开 `.md` 文件看到的就是排好版的正文，不是一堆 `#` 和 `*`。想改哪句就点哪句，语法标记只在你光标所在的那一段出现，改完移开，又回到干净的排版。

## 这是什么

表格、代码块、公式、流程图全都**就地编辑**：不用切到"源码模式"，也不用按预览键。写完之后一键导出 PDF / Word / HTML / EPUB。

**平台支持**：已实测发布的是 **Windows**。macOS / Linux 尚未验证，因此暂不提供 。

## 功能

| 能力 | 说明 |
| --- | --- |
| **所见即所得** | 标题 / 加粗 / 斜体 / 删除线 / 行内代码 / 引用 / 有序无序列表 / 任务列表 / 表格 / 图片 / 链接 / 分割线，双向无损转换 |
| **光标感知语法** | `# `出标题、`- `出列表、`[ ] `出任务列表；行内 `**粗体**` 在光标进入时现身，离开即隐藏 |
| **代码块** | 内嵌 CodeMirror 6：行号、折叠、括号闭合与补全，语法高亮按需加载，百余种语言 |
| **Mermaid 图表** | 代码块标注为 mermaid 即直接渲染成图，点一下回源码改 |
| **数学公式** | 行内 `$…$`、块级 `$$…$$`，**KaTeX 本地渲染**（字体随包发布，**完全离线**，零 CDN 请求）；点公式即在上方浮出可编辑源码框，逐键实时预览 |
| **大纲与三栏** | 标题自动收集、滚动联动、点击跳转；大纲可放左栏页签，也可切到编辑区右侧变成"目录｜正文｜大纲"三栏 |
| **导出** | PDF / HTML / Word / EPUB，公式与图表一并渲染好 |
| **多窗口** | 一个窗口一篇文档，一个文件只开一个窗口；下次启动回到上次的文档与光标位置 |
| **三种主题 × 三种语言** | 亮色 / 暗色 / 羊皮纸；简体中文 / English / Русский |
| **全局搜索** | `Ctrl+Shift+P` 跨文档全文检索（本地索引，不出本机） |

## 为什么它顺手

- **写作面干净**：不需要的工具栏默认收起，界面里只剩你的文字；要排版时用快捷键、右键菜单或顶部菜单。
- **改样式不用切模式**：所有编辑都是"在排版上直接改"，没有源码模式与预览模式之间的往返。
- **公式与图表本地渲染**：断网、内网、离线笔记本上都正常，也不会把文档内容发到任何外部服务。
- **数据在你自己磁盘上**：自动保存可选、每次覆盖前留历史快照、崩溃或关窗前会问你"是否保存更改"。
- **不打扰**：不弹登录框、不要求联网激活、不收集文档内容（诊断信息只含版本与设置快照，可自己看一眼再复制）。

| 层 | 选型 |

## 下载与安装

1. 到本仓库的 **Releases** 页面下载最新的 Windows 安装包（`.exe`）。
2. 双击安装，按向导完成（可选安装路径、创建桌面快捷方式）。
3. 首次启动若出现 **"Windows 已保护你的电脑"**：这是因为安装包**尚未做代码签名**，点「更多信息」→「仍要运行」即可。

**系统要求**：Windows 10 / 11（64 位）；约 400 MB 磁盘空间。

> 想同时开多个窗口？可以 —— 应用内「文件 → 新建窗口」，或直接双击另一个 `.md` 文件。

## 已知限制

| 项 | 现状 | 计划 |
| --- | --- | --- |
| 代码签名 | ❌ 安装包未签名，Windows 会提示"未知发布者" | 卡在外部资源：签名证书尚未办妥，所以不放占位签名 |
| macOS / Linux | ❌ 未验证，暂不提供 | 需要真实桌面环境做完整验收，不发布没验过的包 |
| 自动更新 | ❌ 暂未内置 | 需要稳定的分发地址与签名链路，先手动下载新版本 |
| 超长文档性能 | ✅ 大文档滚动流畅；十万字量级建议适当分篇 | 极端长文（数十万字）的虚拟滚动 |
| 少数扩展语法 | ✅ 常见写法都保真，脚注原样透传 | 继续补齐更冷门的 Markdown 扩展语法 |
| 版本回滚 | ✅ 每次覆盖前自动留快照，可从菜单查看并载入编辑器 | 快照保留条数做成可配置 |
| 行尾格式 | ✅ 自动识别 CRLF / LF，状态栏可点切换 | 多窗口同时编辑的极端场景 |
| 查找替换 | ✅ 支持正则与捕获组，两种编辑模式都可用 | — |
| 输入法（中文 / 日文） | ✅ 已适配主流输入法；若遇异常请反馈 | 收集更多输入法样本 |
